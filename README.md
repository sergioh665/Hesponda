# Hesponda

Projeto simples para enviar lembretes via WhatsApp usando seu próprio número (via WhatsApp Web).

Início rápido

1. Copie o exemplo de variáveis de ambiente:

```bash
cp .env.example .env
```

2. Instale dependências:

```bash
npm install
```

3. Inicie o bot (vai abrir/usar uma sessão do WhatsApp Web):

```bash
npm start
```
